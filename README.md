# TochiNuri

Web app para apuntar entrenos de CrossFit: ejercicios, rondas, reps, kilos y tiempo, progreso y récords, reto semanal con racha, estadísticas mensuales, calculadora de RM, ciclo, molestias, modo parejas y tienda de TochiCoins.

- Web estática (sin compilación) publicada en Netlify.
- Cuentas y datos en Supabase (ver `supabase/schema.sql`).
- Más detalles en `LEEME.md`.
